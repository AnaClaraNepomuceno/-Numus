## 📘 Sobre o Projeto

O NUMUS é um sistema desenvolvido para facilitar o controle financeiro pessoal por meio de uma interface moderna, responsiva e intuitiva.
O projeto une Django no back-end com um front-end elegante (algumas páginas usam TailwindCSS), trazendo recursos como:

- Saldo e movimentações
- Previsão financeira automática
- Metas financeiras
- Análise de risco
- UX clara e amigável

O NUMUS foi pensado para ser simples para iniciantes, mas poderoso para quem deseja aprofundar-se nas suas finanças.

## ✨ Funcionalidades Principais
### Dashboard Dinâmico - Resumo completo com:

- Saldo geral
- Gastos por categoria
- Comparativos mensais

### Entrada/Saída Inteligente

- Formulários claros, cálculo automático e filtros rápidos.

### Previsão Financeira - O sistema usa seus dados históricos para:

- Projetar saldo futuro
- Encontrar riscos
- Prever metas a longo prazo

### Metas Personalizadas - Crie metas com:

- Valor
- Data limite
- Progresso visual

## 🚀 Como Rodar o Projeto
1️⃣ Clonar o repositório
git clone https://github.com/seuusuario/numus.git
cd numus

2️⃣ Instalar dependências do Django
pip install django

3️⃣ Rodar o backend
python manage.py runserver

4️⃣ Visualizar o front-end

Abra qualquer arquivo dentro de:

frontend/pages/
